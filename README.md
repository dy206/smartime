# זמני עבודה – בניית ה-APK בלי תוכנה במחשב

## מה זה
אפליקציית אנדרואיד למדידת זמני עבודה לכמה פרויקטים, מותאמת למסך קטן (כ-240×320dp) ולמקשים פיזיים.
הבנייה נעשית בענן של GitHub, בחינם, והכול מהדפדפן.

## בנייה ראשונה (כ-10 דקות)
1. הירשמו ל-github.com (חינם) והתחברו.
2. לחצו על + למעלה ← New repository. תנו שם (למשל WorkTimer), בחרו **Private** ולחצו Create repository.
3. חלצו את קובץ ה-ZIP במחשב (לחיצה ימנית ← Extract / Open).
4. במאגר לחצו "uploading an existing file". גררו פנימה **את כל התוכן** של תיקיית WorkTimer, כולל התיקיות app, keystore ו-.github. לחצו Commit changes.
   - אם התיקייה .github לא הועלתה (היא מוסתרת): לחצו Add file ← Create new file, כתבו בשם הקובץ `.github/workflows/build.yml`, הדביקו את התוכן מהקובץ build.yml שבחבילה ושמרו.
5. עברו ללשונית **Actions**. אם מופיע כפתור הפעלה, לחצו עליו. בחרו "Build APK" ← Run workflow.
6. המתינו כ-5 דקות עד לסימון וי ירוק. לחצו על הריצה, וגללו למטה ל-Artifacts.
7. הורידו **WorkTimer-apk**, חלצו את ה-ZIP וקבלו את הקובץ app-release.apk.

## התקנה בטלפון
1. העבירו את ה-APK לטלפון (USB, או הורדה ישירה מהדפדפן).
2. אשרו "התקנה ממקורות לא ידועים" אם הטלפון מבקש.
3. פתחו את הקובץ ולחצו התקן.

## עדכון
העלו קבצים חדשים לאותו מאגר, המתינו לבנייה והתקינו את ה-APK החדש **מעל** הקיים. אל תסירו קודם: החתימה קבועה, והנתונים נשמרים. גבו לפני כל עדכון (עוד ← גיבוי ושחזור).

## אם הבנייה נכשלה
היכנסו לריצה שנכשלה (X אדום), העתיקו את שורות השגיאה האדומות ושלחו לי.

## חשוב
- שמרו את המאגר פרטי: מפתח החתימה נמצא בתיקיית keystore.
- אל תמחקו את תיקיית keystore. בלעדיה לא יהיה אפשר לעדכן מעל הגרסה הקיימת.
